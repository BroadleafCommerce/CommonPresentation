# Broadleaf Common Presentation 2.1.0-GA

_Released on Oct 15, 2026_

This is the initial release for the Broadleaf Common Presentation 2.1.x module. This module requires Broadleaf Framework 7.1.0-GA or greater.

# An at-a-glance view of the issues that were closed in this release:

### Enhancements(3)
- Upgraded the BLC dependencies like Broadleaf Framework 7.1.x, Module Parent and other BLC modules.
- Updated module to support baseline dependencies upgrade like Spring, Hibernate and other libraries.
- Removed deprecated Thymeleaf variable modifier processors `AbstractBroadleafVariableModifierProcessor` and `BroadleafVariableModifierProcessor`.
